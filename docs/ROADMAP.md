# Roadmap

1. **Foundation:** repo structure, mobile/browser shells, map/routing/geocoding clients, D1 schema and architecture boundaries.
2. **Buildable mobile:** generate Android/iOS native projects, configure permissions, verify MapLibre Native, produce signed internal test builds.
3. **Navigation engine:** GPS watch lifecycle, map matching, maneuver state, debounced off-route/wrong-way detection, safe rerouting and audio focus.
4. **Offline maps:** regional package manifest, checksum validation, download/resume, offline graph activation, map tiles and POI search.
5. **Voice and AI:** whisper.cpp + Piper + llama.cpp, local model selector, constrained tools, Bangla/English conversation and personalities.
6. **Self-hosted operations:** reproducible OSM data pipeline, service health monitoring, backup/restore, security and privacy controls.
7. **Validation:** automated tests, accessibility, battery/network profiling, simulated GPS, real-device and supervised real-road testing.

A milestone is complete only after code, tests and evidence are available.
